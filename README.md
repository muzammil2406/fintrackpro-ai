# Personal Finance Tracker

A modern, intelligent personal finance tracker designed to help you manage your money with ease. Gain insights into your spending, track your budgets, and achieve your financial goals with a beautifully designed and intuitive interface.

## ✨ Features

- **Dashboard Overview:** A comprehensive summary of your income, expenses, and savings at a glance.
- **Transaction Management:** Easily add, edit, and delete your income and expense records.
- **Budgeting Tools:** Set monthly budgets for different categories and track your progress.
- **Visual Analytics:** Interactive charts to help you understand your spending patterns and savings growth.
- **AI-Powered Insights:** Get personalized financial tips and recommendations generated by AI.
- **Secure Authentication:** User accounts powered by Firebase Authentication.
- **Responsive Design:** A seamless experience across desktop, tablet, and mobile devices.
- **Light & Dark Mode:** Choose the theme that's easiest on your eyes.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [ShadCN UI](https://ui.shadcn.com/)
- **Generative AI:** [Google Gemini](https://ai.google.dev/) via [Genkit](https://firebase.google.com/docs/genkit)
- **Database & Auth:** [Firebase (Firestore & Authentication)](https://firebase.google.com/)
- **State Management:** React Hooks & Context API
- **Form Handling:** [React Hook Form](https://react-hook-form.com/) & [Zod](https://zod.dev/)
- **Charting:** [Recharts](https://recharts.org/)
- **Testing:** [Jest](https://jestjs.io/) & [React Testing Library](https://testing-library.com/)

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

- [Node.js](https://nodejs.org/en/) (v18 or later)
- [pnpm](https://pnpm.io/) (or npm/yarn)

### 1. Clone the repository

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2. Install dependencies

```bash
pnpm install
```

### 3. Set up Environment Variables

You'll need to connect the application to your own Firebase project and Google AI services.

- Create a Firebase project at [firebase.google.com](https://firebase.google.com/).
- In your Firebase project, enable **Firestore** and **Authentication** (with the Google provider).
- Get your Firebase configuration keys from your Project Settings.
- Get a **Gemini API Key** from [Google AI Studio](https://aistudio.google.com/app/apikey).

Next, create a `.env.local` file in the root of the project by copying the example file:

```bash
cp .env .env.local
```

Now, open `.env.local` and add your actual API keys and project details:

```
# Firebase Configuration
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_auth_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_storage_bucket
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
NEXT_PUBLIC_FIREBASE_MEASUREMENT_ID=your_measurement_id

# Google AI (Gemini)
GEMINI_API_KEY=your_gemini_api_key
```

### 4. Run the development server

```bash
pnpm dev
```

Open [http://localhost:9002](http://localhost:9002) with your browser to see the result.

## ☁️ Deployment

This project is optimized for deployment on [Vercel](https://vercel.com/), the creators of Next.js.

1.  **Push your code** to your GitHub repository.
2.  **Import your project** on Vercel.
3.  **Add the Environment Variables** from your `.env.local` file to your Vercel project settings. This is a crucial step for the deployed app to connect to Firebase and Google AI.
4.  **Deploy!** Vercel will automatically build and deploy your application. Any subsequent pushes to your main branch will trigger automatic deployments.
